What it does

It replaced the subscription app I was paying for. It runs the trainer, the workout and the ride file, and it can run more than one rider on the same computer.

ERG control
Your trainer gets the target over Bluetooth FTMS ERG and holds it. You pedal and the resistance follows the workout.
Several riders, one machine
Two or more people can ride one session on the same computer. Everyone gets their own trainer, heart rate strap, targets and FIT file.
A FIT file for every ride
Every session is saved as a standard FIT file. Download it from History, or let it upload to Garmin Connect.
Workouts and plans
The repo comes with workouts and multi-week plan templates as JSON. You can write your own and check the whole library with one command.
Garmin import and upload
Drop a Garmin account export into the import folder and your old rides come back in. Turn on auto-upload in a profile, save a Garmin login once, and new rides go up on their own.

Every workout is a flight to a new system.

I wanted it to look like Interstellar and fly like Elite Dangerous. So every system has something huge in it: a black hole bending the starlight around it, a blue supergiant, or two stars orbiting each other. The game only reads the trainer and the workout. It never changes your targets.

The mission clock

You get there by finishing the workout. How hard you push changes what you find when you arrive. It never decides whether you arrive.

Surveys

Every cruise, climb and burn leg is a survey chance. Stay within 10% of the target for 85% of the leg (the first five seconds don't count, so ERG can settle) and the survey locks. A probe flies to the planet, and when you arrive it lights up a ring, a moon or a station. Going over target doesn't count.

Pursuits

Every burn is a chase. A raider warps in ahead of you, and while you're on target your ship shoots at it and the lock fills. Finish the burn clean and it goes down. Miss it and it gets away. Nobody takes damage, and the lock is the same number the survey uses.

Your star map

Each rider has a voyage page with every system they've reached and the surveys they locked. The next stop is already picked, so a planned workout already has a destination.

Riding together

With two or more riders, everyone flies to the same destination and chases the same raider. Hold your zones together and a tether links the ships. If someone's cadence drops, someone else can cover by riding 10% over their own target for fifteen seconds. A shield goes up around the struggling ship in the helper's color.

Hardware

The server runs on the computer next to the bike and talks to the trainer over Bluetooth. There's no account and nothing to sign up for.

Trainer
I've only tested it on my own Wahoo KICKR CORE, over Bluetooth FTMS ERG. Other FTMS trainers might work. I just haven't tried one.
Heart rate
Any Bluetooth strap that uses the standard Heart Rate Service.
Computer
macOS and Node 24. The Bluetooth library is a native addon, so the server needs Node. Bun won't run it.
Your data
Rides and profiles live in ~/.opencycle by default. Set OPENCYCLE_DATA_DIR to put them somewhere else.

Run it

You don't need a trainer to try it. The simulator fakes two trainers and two heart rate straps, and pnpm demo opens it in your browser.

Shell 
git clone https://github.com/rlfleming93/openCycle.git
cd openCycle
pnpm install
pnpm demo

Create a profile, pick a workout and start a session. The demo keeps its data in a temp folder, so it won't touch real rides. You need Node 24 and pnpm.

For real rides on a Mac, run pnpm app. It builds an openCycle app into your Applications folder. Open it, allow Bluetooth once, and it starts everything and opens the browser. Quit it from the menu bar. On any other computer, pnpm start serves the whole thing on port 4000.

There's no login.

Anyone who can reach the server can start sessions, change profiles and read ride data. Run it on a home network you trust. Don't put it on the internet.

The server listens on your whole network so a TV or tablet can show the ride. OPENCYCLE_HOST=127.0.0.1 keeps it on this computer.
